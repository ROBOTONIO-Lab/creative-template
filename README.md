# 🎮 ROBOTONIO — Το παιχνίδι μου (Creative Programming 2)

Αυτό είναι το repository του **δικού σου** παιχνιδιού για τη χρονιά 2026-27.
Φτιάχτηκε από το template του ROBOTONIO — το περιβάλλον είναι ήδη έτοιμο, δεν εγκαθιστάς τίποτα.

## 🚀 Πώς δουλεύω

1. **Άνοιξε το Codespace:** πράσινο κουμπί **Code → Codespaces → Create codespace on main**.
   Την πρώτη φορά αργεί 1-2 λεπτά (στήνεται ο υπολογιστής σου στο cloud). Αν κολλήσει σε «Connecting…», κάνε ανανέωση (F5).
2. **Γράψε κώδικα** στο `main.py`.
3. **Τρέξε το παιχνίδι σου** — στο τερματικό, μία εντολή:

   ```
   bash tools/run-game
   ```

   Μετά άνοιξε το **port 8000** από την καρτέλα **Ports** (εικονίδιο υδρογείου 🌐). Η πρώτη φόρτωση θέλει έως 1 λεπτό.
4. **Άλλαξες κώδικα;** Σταμάτα τον server (Ctrl+C) και ξανατρέξε `bash tools/run-game` — ο browser δείχνει το *χτισμένο* παιχνίδι, όχι το αρχείο σου.
5. **Πριν φύγεις:** αποθήκευσε τη δουλειά σου στο GitHub (commit + push) και **Stop Codespace**.

## 🔍 Αν κάτι δεν δουλεύει

- Το παιχνίδι δεν φορτώνει; Καρτέλα **Ports** → δεξί κλικ στο 8000 → **Port Visibility → Public**.
- Θες να δεις τα λάθη (Tracebacks) ή τα `print`; Στη σελίδα του παιχνιδιού: **F12 → Console →** γράψε `debug()` **→ Enter**.
- Γκρίζα οθόνη χωρίς τίποτα; Μάλλον έσβησες το `import pygame` ή το `await asyncio.sleep(0)` από το `main.py`.

## 📂 Τι έχει μέσα

| Αρχείο | Τι είναι |
|---|---|
| `main.py` | Ο κώδικας του παιχνιδιού σου — εδώ δουλεύεις |
| `tools/run-game` | Το «κουμπί» που χτίζει και τρέχει το παιχνίδι |
| `.devcontainer/` | Η συνταγή του έτοιμου περιβάλλοντος (μην το πειράζεις) |
